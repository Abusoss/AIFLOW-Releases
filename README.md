# AI Flow

Téléchargements officiels et mises à jour signées d’AI Flow pour macOS et Windows.

Ce dépôt contient uniquement la documentation publique et les fichiers de distribution. Le code source est conservé dans un dépôt privé séparé.

Les versions seront disponibles dans [Releases](https://github.com/Abusoss/AIFLOW-Releases/releases). Dans AI Flow, utilisez **Paramètres → Mises à jour** pour vérifier manuellement les nouvelles versions.

Les modèles et données personnelles ne sont pas inclus dans les mises à jour.
